# 装饰与合成效果预算

适用于现有求职主页；保持拼贴、文件夹照片弹出、纸飞机牵引卡片和桌面互动。

| 项目 | 桌面（宽度 > 768px） | 手机与窄屏（宽度 ≤ 768px） |
| --- | --- | --- |
| 背景星星节点 | 最多 46 颗 | 最多 16 颗 |
| 每颗星星的动画 | 闪烁 + 摇摆 | 仅闪烁 |
| 同时存在的点击星星 | 最多 6 颗，保留最新的 | 同左 |
| 背景模糊 | 仅底部导航保留 16px blur | 无 |
| 菜单栏背景模糊 | 无 | 无 |
| `will-change` 默认值 | `auto` | `auto` |
| 文件夹照片连续动画属性 | `transform` | `transform` |

## 生命周期

- 桌面装饰、时钟和小镜复用同一个桌面可见性状态。页面非当前页、浏览器处于后台或桌面可见面积不足 1% 时暂停。
- 离开桌面或开启减少动态效果时丢弃点击星星，避免恢复后重放。
- 小镜只在获允许运动的行走或拖动阶段启用 `will-change: transform`。
- 图标、窗口和贴纸保留原有的拖动期间提示。
- 关于页滚动变化时，为飞机和卡片短暂启用 transform 提示；退场滚动为电脑和文字区域启用各自需要的提示。最后一次有效变化后 180ms 释放，切页、模式切换和卸载也会取消。
- 项目截图不再显式设置常驻提示。不要为了分层而给每个装饰元素添加 `will-change`。

## 绘制与视觉

- 文件夹照片的布局尺寸固定为展开尺寸，用平移、旋转与缩放表达收起/展开；桌面和手机的原有展开终态坐标保持一致。
- 卡片、文件夹前盖和照片不连续插值阴影参数；固定状态的阴影仍保留。
- 小镜与拖动图标的 drop-shadow、大窗口 box-shadow 经本机短录制检查后保留；尚无足够证据表明移除它们能带来有意义的收益。
- 预算约束的是应用声明和活动数量，不保证浏览器的实际图层数；transform 和 opacity 也不能保证永不重绘。

## 验证与录制（2026-11-13）

- 在同一台机器的 Chromium 上，对生产静态构建进行相同的 4 轮文件夹展开/收起：Layout 事件 792 → 0；Paint 事件 3764 → 1200；Paint 总耗时约 253.2ms → 43.5ms。
- 1440、768、390px 展开照片的边界坐标与修改前记录一致；键盘聚焦可打开，无横向溢出。
- 浏览器回归覆盖 14 项预算/生命周期检查，并保留原有拖拽、阅读和小镜回归。节点数量和动画使用同一个 768px 视口断点，滚动条占位不会使二者分叉。
- 本机录制不能替代真机 FPS、GPU 内存或长期功耗测量，不据此引入统一限帧。
- 原始对照脚本、压缩 trace、截图和检查报告位于本地忽略目录 `.tmp-deploy/decoration-qa/`，不随站点发布。

常规检查：`npm test`、`npm run lint`、`npm run build`。新增装饰时应先核对上述数量与生命周期，再用相同输入录制绘制成本。
